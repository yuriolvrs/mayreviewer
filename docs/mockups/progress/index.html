Progress — Option A mockup

Study-loop home for goals, streaks, restores, and milestones. Walk the flow:

1 · Progress page

Goal, streak with week dots, at-risk restore, milestone claims. Sections, not boxes.

 2 · Reviewers list

One quiet line where “Today 0/10” sits today — goal plus streak, nothing more.

 3 · Reviewer detail

Unchanged — no per-reviewer streak anywhere. The streak is global.

Each page has a Mobile / Desktop toggle — mobile shows the phone column plus bottom tab bar, desktop the top nav. Desktop top nav carries a Progress link on every page, so the page is reachable from anywhere.
